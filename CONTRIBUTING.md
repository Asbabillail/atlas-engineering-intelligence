# Contributing to ATLAS

Thanks for considering a contribution! ATLAS is an early-stage collection of task-oriented developer skills.

## Ways to help

- Propose clear improvements to intent interpretation, debugging, design, and code-review workflows.
- Add realistic, *manual* or automated evaluation cases with explicit expected behavior.
- Report confusing instructions, missing constraints, or compatibility problems.
- Improve documentation and translation without silently changing intent.

## Pull request checklist

1. Explain the user-facing behavior being improved.
2. Keep changes focused and maintain existing capability boundaries.
3. Run `python scripts/validate_plugin.py`.
4. Update tests or documentation when behavior changes.
5. Identify any real tools, external resources, or dependencies used.
6. Do not include API keys, customer information, private code, or unauthorized third-party material.
7. Don't assert that tests or benchmarks passed unless you actually ran them.
