# ATLAS — Install and configure

See **[Platform compatibility](PLATFORM_COMPATIBILITY.md)** first. Installing source from GitHub in one host does not activate it in another host.

## ChatGPT
Use the account's installed ATLAS private plugin or an eligible plugin-import route. Import the plugin ZIP generated by `python scripts/package_plugin.py`; connect GitHub/Vercel tools only through authorized integrations.

For an existing Custom GPT that still supports editing: use `adapters/chatgpt/INSTRUCTIONS.md` as the instruction text. As of Oct 2026 personal accounts cannot create new GPTs; plugins are the migration path.

## Claude
Generate `python scripts/export_adapters.py`; import relevant *individual* `dist/claude-skills/*.zip` through Claude's custom Skills feature when your account supports it. For Claude Code, add desired folders to `.claude/skills/` in your own project, or put `CLAUDE.md` at the project root.

## Gemini
Gemini Apps Gem: paste `adapters/gemini/GEM_INSTRUCTIONS.md` in Gem Instructions; optionally attach skill reference files. Gemini CLI: install this repository as an extension using the current CLI extension flow, or copy `GEMINI.md` as project context. Review extension files first.

## Other coding assistants
For Codex and compatible agents, copy `AGENTS.md` into the **target project**. For Copilot, copy `.github/copilot-instructions.md` into the target project's `.github/` folder. Adapt to each host's rules.

## Verify

```bash
python scripts/validate_plugin.py
python scripts/package_plugin.py
python scripts/export_adapters.py
```

The tools test structural consistency and packaging only. Evaluate behavior on the actual assistant using `tests/CROSS_PLATFORM_ACCEPTANCE.md` and record empirical outcomes.
