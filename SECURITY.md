# Security policy

ATLAS is a **skills-only instruction package**, not a deployed backend or a security scanner. It does not include API keys or network services.

If you identify security-sensitive content, dangerous instructions, or an issue affecting user data, please avoid posting credentials, exploit details, or private information in a public issue. Contact the repository maintainer using the private contact or security-reporting option the maintainer configures before enabling public issue reporting.

There is no stated response-time SLA. The `atlas-security` skill provides review guidance, not a guarantee of vulnerability detection or system safety.
